# Welcome to Conway's Game of Life!
This uses the terminal to display an interesting simulation of "life".
We start with a grid of cells, either alive or dead. Here are the rules:
1) Any live cell with fewer than two live neighbors dies, as if by underpopulation.
2) Any live cell with two or three live neighbors lives on to the next generation.
3) Any live cell with more than three live neighbors dies, as if by underpopulation.
4) Any dead cell with exactly three live neighbors becomes a live cell, as if by reproduction.

You can customize your shape, board size, and speed in the code file. 
You'll need the shape files to start a simulation.
You can also make a shape file yourself!

Note that your terminal needs to stay scrolled to the bottom, so the simulation appears to be updating live.
